# Producción

Antes de aceptar dinero real: confirmar autorización aplicable; implementar verificación de edad/identidad, privacidad, términos, juego responsable, controles antifraude y obligaciones fiscales; contratar proveedor de pagos compatible; configurar HTTPS, secretos, backups, monitoreo, rate limiting, MFA para administración y auditoría.

Los endpoints de dinero real no están habilitados. El RNG de esta demostración no debe utilizarse para apuestas reales; una operación real requiere un sistema de juego apropiadamente auditado/certificado según el modelo autorizado.
